# Evaluation contract
The agent accepts only capability_probe and fourw-native-synthetic-v1 requests with scope=synthetic_build_only. Each request must carry all eight frozen authority/rule/schema dependencies and a canonical-only approved knowledge release. Maximum 16 records per sequential request and 128000 UTF-8 request bytes. Never truncate rules to fit.
The demo creates its own artificial workbook, exact mapping and source-bound case references. It will not accept a user-supplied workbook for preparation. Native responses must contain the exact request_id and each expected case_ref exactly once. Missing or invalid assessments remain technical failures.
The coordinator preserves the first response as immutable bytes and records the observed native invocation, model and settings separately. Self-reports are not evidence of enforcement. The deterministic transport check intentionally creates processing failures for every row without inference; it is not a scoring demonstration.
Original input hashes are checked on preparation, acceptance and delivery. Outputs use exclusive paths. A verified completed delivery can be reused with its receipt; changed dependencies or unknown partial state stop. Only one active model request may run at a time. The model wait ceiling is 300 seconds per synthetic request with no automatic model retry.
All six safeguards remain: actionable malformed-workbook errors; unchanged source artifacts; no duplicate operation effects; resumable, verified checkpoints; packet leakage/return integrity; approved frozen knowledge with rejection and rollback.
Review import retains its existing separate independence/blinding attestations and cannot fabricate them. Historical exposed reviewer records are outside this package. Candidate learning does not govern scoring. The canonical-only demo release contains no learned lessons.
